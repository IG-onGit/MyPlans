General

MyPlans is a VS Code extension: a personal task manager that reads your .yml / .yaml project files and shows them in a Monokai-themed sidebar panel, so you can plan, track and deploy work without leaving the editor.

Why MyPlans

  • Plans are plain YAML files you can edit by hand and keep in Git.
  • Categories, topics, tasks and steps are all collapsible, with progress bars per category and overall.
  • Add, rename and delete items from the panel, or jump to the exact line in the file.
  • The panel refreshes automatically when a YAML file changes on disk.
  • One button stages, commits and pushes your work.

Next: install the extension, then learn the YAML format.

Installation

Search for MyPlans in the Extensions panel (Ctrl+Shift+X) and click Install, or open the Marketplace page.

Getting started

  1. Open any workspace folder in VS Code.
  2. Click the MyPlans icon in the Activity Bar.
  3. Click + Category to create your first folder.
  4. Inside it, click + Topic to create a YAML file.
  5. Inside the topic, click + Task, then + Step inside the task.
  6. Check steps off as you complete them.

YAML format

Each category is a folder at the top level of your workspace. Each topic is a .yaml file inside it, for example Work/sprint-12.yaml. Files in the workspace root are skipped.

Completing a step

Checking a step comments its line out. Un-checking removes the comment and restores the original line.

  # - Install GitHub Actions runner
  # - Write build.yml workflow
  - Add test step

ASAP flag

Prefix a step with [ASAP] (or click its dot in the panel) to flag it as urgent. The tag is kept when you edit the step.

Fix login bug:
  - [ASAP] Patch token expiry check

Controls and shortcuts

Hover actions

ButtonWhereWhat it does
✎Category / Topic / Task / StepOpens an input box to rename or edit
✕Category / Topic / Task / StepDeletes, with a confirmation dialog
↗Topic / Task / StepOpens the YAML file at that line

Header and row buttons

ButtonWhereWhat it does
+ CategoryTop headerCreates a new category folder
⟳Top headerRefreshes the panel manually
+ TopicCategory rowCreates a new .yaml file in that category
+ TaskTopic rowAppends a task to that topic file

Click any category, topic or task header to collapse or expand it.

Keyboard

Commands

Assign your own keys via File, Preferences, Keyboard Shortcuts and search for MyPlans.

Git deploy

The Deploy button at the bottom of the panel stages your changes, commits with a timestamped message, and pushes.

git add -A
git commit -m "MyPlans: update tasks [YYYY-MM-DD HH:MM:SS]"
git push

The extension runs git add -A, so Deploy commits all changed files in the workspace, not only YAML files.

  • The workspace must be a Git repository.
  • A remote must be configured.
  • Your credentials or SSH key must allow pushing.

The button is disabled when there is nothing to commit or Git is not initialised.

RunningVS Code 1.85 or later

Known limitations

  • Only .yml and .yaml files are scanned.
  • Files must use the Task Name: plus - step format.
  • Categories are direct child folders of the workspace root.
